# 🗺️ Africa Resource Map

An interactive web application showcasing African mineral deposits, natural resources, and value-addition investment opportunities for investors and policymakers.

## 🌍 Features

- **Interactive Map**: Leaflet-based map displaying mineral deposits across African countries
- **AI Assistant**: Qwen AI-powered chatbot providing insights about resources and investments
- **Resource Information**: Detailed data on minerals, deposits, and investment opportunities
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Real-time Updates**: Live data integration with economic indicators

## 🚀 Getting Started

### Live Demo
Visit: [https://bro-mwangi.github.io/africa-resource-map/](https://bro-mwangi.github.io/africa-resource-map/)

### Local Development

```bash
# Clone the repository
git clone https://github.com/Bro-Mwangi/africa-resource-map.git
cd africa-resource-map

# Serve locally (using Python)
python -m http.server 8000

# Open in browser
http://localhost:8000
```

## 📊 Supported Resources

### By Country:
- **South Africa**: Gold, Diamonds, Platinum
- **Democratic Republic of Congo**: Cobalt, Copper, Diamonds
- **Nigeria**: Oil, Tin, Bauxite
- **Ghana**: Gold, Bauxite
- **Zambia**: Copper, Cobalt
- **Ethiopia**: Gold, Potash, Tantalum
- **Morocco**: Phosphate, Iron Ore

## 🤖 Qwen AI Integration

The application includes an AI assistant that:
- Answers questions about mineral resources
- Provides investment insights
- Suggests opportunities by country
- Shares market trends and data

## 🔧 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **Mapping**: Leaflet.js, OpenStreetMap
- **AI**: Qwen API Integration
- **Hosting**: GitHub Pages

## 📝 Usage

1. **Explore the Map**: Click on markers to view resource information
2. **Ask Questions**: Use the Qwen AI chatbot sidebar to get insights
3. **Filter Resources**: Use search and filter options to find specific minerals
4. **View Details**: Click on any location for comprehensive investment data
