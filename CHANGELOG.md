# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-13

### Added
- Initial release of Africa Resource Map
- Interactive Leaflet map with mineral deposit markers
- Qwen AI chatbot assistant
- Support for 7 African countries
- Responsive design for desktop and mobile
- Chat-based resource information system
- Resource filtering and display
- Real-time marker interaction

### Features
- South Africa: Gold, Diamonds, Platinum
- Democratic Republic of Congo: Cobalt, Copper, Diamonds
- Nigeria: Oil, Tin, Bauxite
- Ghana: Gold, Bauxite
- Zambia: Copper, Cobalt
- Ethiopia: Gold, Potash, Tantalum
- Morocco: Phosphate, Iron Ore

### Technical
- Leaflet.js for mapping
- OpenStreetMap tiles
- Vanilla JavaScript (no frameworks)
- GitHub Pages hosting
